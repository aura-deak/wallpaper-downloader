# wallpaper-downloader
从 Steam 创意工坊批量下载 Wallpaper Engine 壁纸的命令行工具。通过调用 [DepotDownloader](https://github.com/SteamRE/DepotDownloader) 实现壁纸资源的下载。

## 快速开始

1. 下载或安装depotdownloader。
- 使用AUR里的包`yay -S steamdepotdownloader-bin`
- 或前往[DepotDownloader Releases](https://github.com/SteamRE/DepotDownloader/releases)

2. 运行本程序，根据指示进行操作
